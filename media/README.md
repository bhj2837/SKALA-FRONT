## 용량 메모

사진은 장당 500KB 안쪽, 영상은 20MB 안쪽으로 줄여 넣는 편이 좋습니다.

```bash
ffmpeg -i 원본.mp4 -vf scale=1280:-2 -crf 28 trip.mp4
```
